# 💧 Water Bill Generator for Apartments

A Python-based web application built with **Streamlit** that helps apartment administrators calculate and generate water bills quickly and accurately.

## 📖 Overview

Managing monthly water bills manually can be time-consuming and prone to errors. This application automates the billing process by calculating each flat's water consumption and generating bills through a simple and user-friendly interface.

## ✨ Features

* 🏢 Apartment login interface
* 🚰 Enter water meter readings for each flat
* 📊 Automatic water consumption calculation
* 💰 Generates water bills based on consumption
* ⚡ Fast and accurate calculations
* 🖥️ Easy-to-use Streamlit interface

## 🛠️ Technologies Used

* Python
* Streamlit
* OpenPyXL
* Pandas
* NumPy

## 📂 Installation

Clone the repository:

```bash
git clone https://github.com/Ashu27022011/Water-bill-generator-for-apartments.git
```

Move into the project directory:

```bash
cd Water-bill-generator-for-apartments
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

> Replace **app.py** with your main Python file if it has a different name.

## 🚀 How It Works

1. Log in as the apartment administrator.
2. Enter apartment and flat details.
3. Input the current water meter readings.
4. The application calculates water usage automatically.
5. Water bills are generated for every flat.
